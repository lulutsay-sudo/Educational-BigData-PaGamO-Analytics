# 第 08 週：學習成效與學習風險分析報告

- **專案名稱**：基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
- **資料範圍**：國小五年級 4 個班級學生 PaGamO 作答數據 (共 116 人，10,788 筆紀錄)
- **維護時間**：第 8 週實作成果歸檔

---

## 一、 分析目標與三級風險評估架構

本週分析聚焦於「學習成效預測」、「學習參與度與成效之關係」以及「落後早期預警機制建置」。為避免一刀切導致「預警過度（警報疲勞）」之問題，本專案建立**三級風險預警機制**：

1. **三級預警目標變數 (Target Variable)**：
   - **高風險 (需優先抽問)**：平均正確率 < 35% 或 任務完成率 < 50%（約佔全年級 30%）。
   - **中風險 (觀望提醒)**：35% ≤ 平均正確率 < 50% 且 完成率 ≥ 50%（約佔全年級 34%）。
   - **低風險 (學習穩定)**：平均正確率 ≥ 50% 且 完成率 ≥ 50%（約佔全年級 36%）。
2. **評估指標 (Evaluation Metrics)**：
   - 參與度指標：任務完成率 (%)。
   - 行為指標：平均作答時間 (秒)。
   - 相關性指標：完成率與正確率之相關係數 (Pearson Correlation)。

---

## 二、 軌道一：全年級整體學習成效與風險分析 (Macro Analysis)

### 1. 全年級整體分佈與風險結構
- **金字塔分佈**：三級分級呈現極佳的辨識度，能將有限的補救教學資源精準鎖定在 30% 的高風險群體上。
- **整體趨勢**：各班級平均完成率普遍高於 75%，顯示學生基本參與度良好，但正確率落差大，需進一步進行微觀行為診斷。

---

## 三、 軌道二：各班導師微觀診斷與早期預警 (Micro Analysis)

透過 Python 腳本對各班進行精準診斷，自動篩選出「高風險群體」進行行為模式分析：

### 1. 早期預警學生診斷分類
針對篩選出的核心高風險學生，可明確區分為兩種異常行為模式：
- **模式 A（高完成率 + 極低正確率 + 極短作答時間）**：
  - *診斷*：典型的「快猜應付型」，學生為了獲得獎勵而隨意猜題，導師需重點要求其拉長閱讀與思考時間。
- **模式 B（高完成率 + 低正確率 + 長作答時間）**：
  - *診斷*：屬於「閱讀理解困難型」，學生態度認真但正確率偏低，導師應介入給予文章閱讀策略輔導。
