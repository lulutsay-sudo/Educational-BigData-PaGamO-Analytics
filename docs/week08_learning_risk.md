# 第 08 週：學習成效與學習風險分析報告

- **專案名稱**：基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
- **資料範圍**：國小五年級 4 個班級學生 PaGamO 作答數據 (共 174 人，10,788 筆紀錄)
- **維護時間**：第 8 週實作成果歸檔

---

## 一、 分析目標與評估架構

本週分析聚焦於「學習成效預測」、「學習參與度與成效之關係」以及「落後早期預警機制建置」。透過數據分析兼顧年級整體決策與班級個別輔導的需求：

1. **目標變數 (Target Variable)**：
   - **學習成效**：平均正確率 (%)。
   - **早期預警風險**：定義正確率 < 60% 或任務完成率 < 50% 者為「高風險(需關注)」學生。
2. **評估指標 (Evaluation Metrics)**：
   - 參與度指標：任務完成率 (%)。
   - 行為指標：平均作答時間 (秒)。
   - 相關性指標：完成率與正確率之相關係數 (Pearson Correlation)。

### 2. 早期預警學生診斷分類
針對早期預警清單（如 510 班之高風險學生），可歸納出兩種主要異常行為模式：
- **模式 A（高完成率 + 極低正確率 + 極短作答時間）**：
  - *例如：510_S19（正確率 28.2%，完成率 97.5%，作答時間 45.0 秒）、510_S23（正確率 26.3%，完成率 95.0%，作答時間 34.0 秒）*
  - *診斷*：典型的「快猜應付型」，學生為了快速完成任務獲得獎勵而隨意猜題，導師需重點要求其拉長閱讀時間。
- **模式 B（高完成率 + 中低正確率 + 長作答時間）**：
  - *例如：510_S27（正確率 57.9%，完成率 95.0%，作答時間 152.0 秒）*
  - *診斷*：屬於「閱讀理解困難型」，學生認真作答但正確率偏低，導師應介入給予文本閱讀策略輔導。
