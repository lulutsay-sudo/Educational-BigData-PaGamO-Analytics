# 第 3 週產出：教育研究設計與資料倫理檢核表

## 一、 研究問題與研究假設 (Research Questions & Hypotheses)

| 研究問題 (RQ) | 研究假設 (Hypothesis) | 分析方法 / 驗證方式 |
| :--- | :--- | :--- |
| **RQ1：** 學生在 PaGamO 任務中的作答時間與正確率是否存在顯著相關？ | **H1：** 平均作答時間過短（極端值）的學生，其平均正確率顯著低於全體平均（存在隨機猜題行為）。 | Pearson 相關分析、散佈圖分析 |
| **RQ2：** 能否透過上學期（114-1）的答題歷程，提前預測下學期的學習落後風險？ | **H2：** 上學期任務完成率低於 80% 或未作答次數偏高者，下學期出現學習落後（正確率 < 50%）的機率顯著較高。 | 二元邏輯迴歸 (Logistic Regression)、特徵重要性 |
| **RQ3：** 能否將學生劃分為具備教學意義的學習者輪廓（Learner Profiles）？ | **H3：** 依據作答時間、完成率與正確率，學生可被客觀劃分為「高效精準型」、「沉思細作型」、「敷衍猜題型」與「低參與落後型」四類。 | K-means 聚類分群演算法 |

## 二、 變項設計與操作化定義 (Variables Design)

| 變項類別 | 變項名稱 | 資料型態 | 操作化定義與單位 | 專題用途 |
| :--- | :--- | :--- | :--- | :--- |
| **自變項 (X)** | `平均作答時間` | Continuous | 學生完成每項任務之平均花費秒數（秒） | 衡量學習專注度與思考投入 |
| **自變項 (X)** | `任務完成率` | Continuous | 該學期實際完成任務數 / 應完成任務總數 (0.00 ~ 1.00) | 衡量學習參與度與持續性 |
| **自變項 (X)** | `缺交次數` | Discrete | 顯示「未作答」之任務累積總次數 | 學習拖延與風險預警特徵 |
| **依變項 (Y)** | `平均正確率` | Continuous | 該學期所有已完成任務之平均正確率 (0.00 ~ 1.00) | 衡量學習成效 |
| **標籤變項 (Y)** | `學習落後風險` | Binary | 1 = 高風險（完成率 < 70% 或正確率 < 50%）；0 = 低風險 | 機器學習預測目標 |
