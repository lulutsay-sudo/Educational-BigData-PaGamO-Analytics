# 第 1–2 週專題構想單

## 一、 專題基本資訊
* **專題名稱：** 基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
* **專題類型：** 學習行為分析 / 學習風險預警 / 學習者分群 / 儀表板設計
* **預計工具：** Python (Pandas, Scikit-learn), Looker Studio
* **資料範疇：** 國小五年級 6 個班級（501、504、505、506、507、510），跨 114-1 與 114-2 兩學期 PaGamO 中文閱讀素養任務資料（共 174 位學生，10,788 筆個人任務紀錄）

---

## 二、 教育問題轉化為資料問題

1. **現場痛點 1：無法即時識別「隨機猜題」的學生**
   * **資料問題：** 分析「平均作答時間（秒）」與「平均正確率（%）」的相關性，定義「答題過快且正確率偏低」之極端學習行為。
2. **現場痛點 2：學習拖延或低參與度學生常到期末才發現**
   * **資料問題：** 追蹤「未作答次數」與「任務完成率」的歷程走勢，建立早期風險預警指標。
3. **現場痛點 3：單一教學策略難以兼顧差異化需求**
   * **資料問題：** 運用 K-means 分群演算法，依據時間、完成率與正確率三大維度建立學生學習輪廓（Learner Profiles）。

---

## 三、 研究問題 (Research Questions)

* **RQ1（學習行為分析）：** 學生在 PaGamO 閱讀素養任務中的「作答時間」與「正確率/完成率」是否存在顯著相關？是否存在「時間極短但正確率極低」的猜題行為族群？
* **RQ2（風險預警）：** 能否利用上學期與下學期前期的作答歷程，建立機器學習模型，早期預測學生期末學習落後（完成率低於 70% 或正確率低於 50%）的風險？
* **RQ3（學習者分群）：** 依據投入度（完成率、作答時間）與表現度（正確率），可以將 174 位學生劃分成哪幾類學習者輪廓（如：高效學習型、沉思細作型、敷衍猜題型、低參與拖延型）？
* **RQ4（教育決策）：** 如何設計一套供導師使用的「學習分析儀表板」，將數據結果轉化為具體可行的差異化輔導建議？

---

## 四、 資料倫理與隱私保護聲明

1. **個資去識別化：** 原始資料中之學生姓名已於前處理階段完全刪除，全數替換為匿名代碼（如 `501_S01`）。
2. **資料最小化原則：** 僅擷取與學習行為分析直接相關之數據（作答時間、正確率、完成率、任務得分）。
3. **不作競爭性排名：** 本專題定位為「學習落後預警」與「教學輔導建議」，不進行班級間或學生個人之公開比較與排名。
