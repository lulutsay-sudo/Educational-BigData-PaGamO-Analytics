# 第 13 週：行為文字與任務文本分析報告

* **專案名稱：** 基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
* **報告主題：** PaGamO 任務名稱與作答行為文本之 TF-IDF 關鍵字與錯誤型態分析 (Educational Behavioral Text Analytics)
* **資料來源：** PaGamO 系統實際匯出之學生任務作答歷程記錄（包含各任務名稱、作答狀態、作答時間、正確率與系統標籤等結構化行為文本）
* **維護時間：** 第 13 週實作成果歸檔

---

## 一、 分析目的與資料範圍
本階段旨在對現有的 **PaGamO 實際作答歷程數據**進行文本與特徵探勘。由於本專題核心資料為結構化行為數據（共 174 位學生、10,788 筆個人任務紀錄），本報告將這些量化歷程中的文字欄位（如任務單元名稱、系統分類標籤、答題狀態記錄）進行文本詞頻（TF-IDF）與行為特徵對應分析，藉此識別學生在不同閱讀素養任務單元中的遭遇瓶頸。

## 二、 文字與行為特徵分析結果
1. **任務單元名稱 TF-IDF 關鍵字權重分析**：
   * 透過對學生高頻作答與常失分之任務名稱進行文字探勘，發現涉及「推論理解」、「段落主旨判讀」與「跨文本比較」等關鍵字之任務單元，其整體平均答題時間較長，且正確率呈現顯著下滑。
2. **作答狀態與錯誤行為文本對應**：
   * 結合系統記錄的作答狀態文字，歸納出學生在面對長文本閱讀任務時的常見行為模式，包含「穩定作答型」、「超時未交型」及「快速猜題型」。

## 三、 教育現場應用建議
* **教材難易度動態調整**：依據任務名稱與錯誤文字標籤的對應結果，教師可針對 TF-IDF 權重較高、學生失分率偏高的特定閱讀主題，於課堂中進行補充講解或實施鷹架支持。
* **精準輔導對象鎖定**：結合第 5–12 週建立的 K-means 分群與落後風險預警模型，系統能自動挑選出需要優先輔導的學生與對應的困難任務單元，提升教學干預效率。
