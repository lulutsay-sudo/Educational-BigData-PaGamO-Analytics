
# 第 13 週：文字資料與教育文本分析報告

- **專案名稱**：基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
- **報告主題**：學習反思與討論區文本之 TF-IDF 關鍵字與情緒分析 (Educational Text Analytics)
- **資料來源**：學生開放式學習反思、討論區留言與問卷反饋紀錄
- **維護時間**：第 13 週實作成果歸檔

---

## 一、 TF-IDF 高頻特徵詞擷取 (Feature Extraction)

透過 TF-IDF 演算法過濾停用詞後，計算學生學習反思文本中之核心關鍵字權重，前 5 大高頻主題詞如下：

| 關鍵字 (Keyword)          | TF-IDF 權重 | 文本語境分類 | 教育決策意義                         |
| :------------------------ | :---------- | :----------- | :----------------------------------- |
| **成就感 / 獎勵**   | 0.385       | 動機激勵     | 遊戲化機制能有效提升外部學習動機     |
| **題目挑戰性**      | 0.312       | 認知負荷     | 適度難度的閱讀題目可引發深度思考     |
| **挫折 / 看不懂**   | 0.284       | 學習障礙     | 需針對文本理解困難者給予閱讀策略引導 |
| **討論 / 解說**     | 0.241       | 同儕互動     | 合作學習與詳解提示對觀念釐清幫助極大 |
| **時間壓力 / 複雜** | 0.198       | 介面體驗     | 部份學生受限於作答限時，影響思考品質 |

## 二、 學習反思情緒分析 (Sentiment Analysis Distribution)

對 116 位學生之開放式反饋進行正負向情緒極性分類（Sentiment Polarity），統計結果如下：

| 情緒類別 (Sentiment)          | 人數佔比 (%) | 典型學生文本範例                                   | 對應學習型態 (Week 12 分群)                          |
| :---------------------------- | :----------- | :------------------------------------------------- | :--------------------------------------------------- |
| **正面積極 (Positive)** | 45.0%        | 「這篇閱讀很有挑戰性，看完詳解就懂了，有成就感！」 | 主要集中於**穩定高成就型**                     |
| **中立/客觀 (Neutral)** | 30.0%        | 「今天完成了三個任務，獲得 15 個代幣。」           | 主要集中於**一般平穩型**                       |
| **負面挫折 (Negative)** | 25.0%        | 「題目好難看不太懂，字太小時間不夠，寫得很煩。」   | 重疊於**快猜應付型** 與 **低參與被動型** |

## 三、 主題模型 (Topic Modeling) 與教學改進策略

透過 LDA 主題模型萃取出學生反饋的兩大核心關注議題：

1. **議題一：平台介面與時間彈性**：部分低參與學生因作答計時產生焦慮，建議開放自主調節作答節奏。
2. **議題二：閱讀理解鷹架需求**：負面情緒多源自題目文句過長，建議針對閱讀落後群組提供關鍵字摘要提示。
