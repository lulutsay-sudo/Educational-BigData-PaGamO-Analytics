# 第 5 週產出：教育資料前處理、特徵工程與資料字典

## 一、 週次主題說明
* **主題：** 教育資料前處理與特徵工程 (Educational Data Preprocessing & Feature Engineering)
* **目的：** 將原始 PaGamO 閱讀歷程數據轉化為適合進行機器學習與學習型態分群（Clustering）之定量特徵向量，並建立標準化資料字典。

---

## 二、 PaGamO 學習歷程資料字典 (Data Dictionary)

| 欄位名稱 | 資料型態 | 單位/範圍 | 描述說明 | 對應教育意涵/特徵類型 |
| :--- | :--- | :--- | :--- | :--- |
| `學生ID` | String | - | 學生匿名識別碼 | 核心識別碼 |
| `班級` | String | - | 班級代碼 (如 501, 505) | 班級分組 |
| `學期` | String | - | 學年度標籤 (如 114) | 時間範疇 |
| `平均正確率` | Float | 0.00 ~ 1.00 | 學生於已作答任務之平均答對率 | 學習理解度 (能力指標) |
| `平均作答時間_秒` | Float | 秒 | 學生單一任務平均作答耗時 | 答對思考深度 / 猜題衝動性 |
| `完成率` | Float | 0.00 ~ 1.00 | 學生完成指派任務之比例 | 學習參與度 / 意志力 |
| `完成任務數` | Integer | 個 | 學生實際完成的文章/任務總量 | 練習量 / 學習活躍度 |
| `總作答時間_秒` | Float | 秒 | `平均作答時間_秒` * `完成任務數` | 平台總學習投入時間 (衍生特徵) |
| `每任務平均投入效率`| Float | 數值 | `平均正確率` / (`平均作答時間_秒` + 1) | 單位時間學習效益 (衍生特徵) |

---

## 三、 特徵工程 (Feature Engineering) 策略說明
1. **參與度特徵建置：** 結合 `完成率` 與 `完成任務數` 代表學生在 PaGamO 平台的自主學習積極度。
2. **理解與耗時互動特徵：** 結合 `平均正確率` 與 `平均作答時間_秒`，用於分辨「高效理解型」、「熟能生巧型」、「盲目猜題型」與「學習困難型」學生。
3. **產出檔案：** 已完成 `data/initial_feature_table.csv` 之構建，準備作為第 6 週 K-Means 分群模型之輸入。
