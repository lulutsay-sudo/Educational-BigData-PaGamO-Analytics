## 二、 核心視覺化圖表分析與教育洞察

### 1. 圖一：整體與班級正確率分佈 (Boxplot)
- **發現**：學生平均正確率主要集中於中高區間，但部分班級存在較多下方離群值（極低正確率）。
- **洞察**：個別學生可能存在隨機猜題或閱讀理解嚴重卡關之情形，需做進一步預警追蹤。

### 2. 圖二：各班級任務完成率 (Barplot)
- **發現**：跨班級的任務完成率呈現些微差異，反映出不同班級導師在課堂推動 PaGamO 閱讀任務的投入度與進度控管差異。

### 3. 圖三：學習行為特徵相關係數熱圖 (Correlation Heatmap)
- **數據特徵關係**：
  - **`平均正確率` 與 `平均作答時間_秒`**：呈現高度正相關 ($r = 0.78$)，顯示作答時間充裕的學生往往能取得更高的正確率；反之，作答時間極短者正確率顯著偏低（符合「敷衍/猜題」行為特徵）。
  - **`完成率` 與 `完成任務數`**：呈完全正相關 ($r = 1.00$)，驗證特徵計算邏輯無誤。
  - **`完成率` 與 `正確率/時間`**：呈中度正相關 ($r \approx 0.39 \sim 0.40$)，說明任務參與度高者，其學習表現亦有一定保障。

### 4. 圖四：K-means 學習型態分群散佈圖 (Scatterplot)
- **分群成果**：利用投入度（完成率、作答時間）與表現度（正確率）順利將 174 位學生劃分為不同的學習者輪廓，為後續 Looker Studio 導師端預警儀表板提供群組標籤。
