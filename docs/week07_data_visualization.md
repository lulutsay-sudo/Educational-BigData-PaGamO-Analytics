# 第 07 週：教育資料視覺化與雙軌探索性分析報告

- **專案名稱**：基於 PaGamO 閱讀素養歷程數據之學生學習型態分群與落後風險預警機制建置
- **資料範圍**：114-1 與 114-2 學期國小五年級學生 PaGamO 作答數據 (共 4 個班級，174 人，10,788 筆紀錄)
- **維護時間**：第 7 週實作成果歸檔

---

## 一、 本週視覺化目標與分析雙軌架構

本週重點為運用 Python (Pandas, Seaborn, Matplotlib) 將前處理與 K-means 特徵工程後的數據進行探索性視覺化分析。為兼顧「全年級宏觀數據治理」與「導師端微觀精準輔導」，本專案建立雙軌分析架構：

1. **軌道一：全年級跨班整體比較 (Macro-Level Analysis)**
   - 目的：評估班級間推動差異、學習型態分佈與年級整體學習規律。
2. **軌道二：各班級導師微觀診斷 (Micro-Level Class Diagnostics)**
   - 目的：產出各班獨立圖表，協助導師精準鎖定班上落後預警學生與學習行為異常者。

---

## 二、 軌道一：全年級整體分析與跨班比較

### 1. 跨班級表現與完成率差異 (`figures/fig1_overall_class_comparison.png`)
- **分析發現**：4 個班級的中位數正確率均維持在 70%~80% 之間，但部分班級存在較多極低正確率（<50%）的離群值。完成率方面，不同班級間呈顯著階層差異，顯示各班導師在課堂上推動 PaGamO 任務的教學節奏與管控強度有所不同。

### 2. 各班學習型態結構分析 (`figures/fig2_overall_cluster_by_class.png`)
- **分析發現**：利用前六週建構之 K-means 聚類標籤，可以看出不同班級的學生型態組成不同。例如某班「自主高投入型」佔比顯著較高，而另一班則集中較多「低投入猜題型」學生，這為學校行政端進行資源分配與跨班輔導提供了數據支持。

---

## 三、 軌道二：各班級導師專用診斷報告

針對 4 個班級已分別繪製並匯出專屬診斷圖表（位於 `figures/class_reports/`）：

### 1. 班級個別分析重點指標（以各班獨立圖表為準）
- **學生行為分佈圖 (`class_reports/class_xxx_report.png`)**：
  - **預警學生鎖定**：落在紅虛線（正確率 60%）下方且作答時間極短（<15 秒）之學生，系統自動標示為「高風險猜題型」，建議導師優先進行一對一課後抽問。
  - **沉浸沉思型**：作答時間長但正確率中等者，屬於「閱讀理解困難型」，需給予閱讀策略引導。

### 2. 班級內部特徵相關性
- **規律診斷**：各班「平均正確率」與「平均作答時間」均展現顯著正相關，驗證「鼓勵學生拉長閱讀與思考時間」是提升該班正確率的通用無痛策略。
